**JDK : Java development kit** 

It includes the JRE , the compiler and the development tools needed to write and run java programs.

**JRE : Java runtime environment**

It includes JVM and the pre written java libraries . It provides the environment to run java programs.

**JVM: Java Virtual Machine**

The main entity that makes java platform independant. The JVM is responsible for running java bytecode.


**ByteCode**

When java code is compiled , a .class file is produced. This .class file contains the java bytecode that can run on any machine that has a JVM.

**Write Once , Run Anywhere (WORA)**

It means that you can write java program once , run it anywhere without changing the code.

When java code is compiled , it produces by a class file containing java bytecode that is platform independant. The java bytecode can run on any machine that contains a JVM. The JVM is specific to the machine on which it is installed .
